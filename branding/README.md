# Panelgrove branding

The app name is **Panelgrove** and its Android package ID is `dev.soto.panelgrove`.

[icon.svg](icon.svg) is the original supplied artwork and the source for the Android launcher icon. Its paths, colors, 108 × 108 view box, and embedded metadata are preserved.

| Color | Value |
| --- | --- |
| Blue background | `#2F4280` |
| Paper | `#F4EFE6` |
| Dark panels | `#1B2B5E` |
| Bookmark | `#F2B8A2` |

Android 8+ uses an adaptive icon with separate background and foreground artwork. Android 13+ also has a monochrome themed-icon variant. The vectors are in `app/src/main/res/drawable/`, with launcher resources in the `mipmap-*` directories.

The normal and themed launcher appearances were visually checked on an API 36 emulator. See the [validation summary](../docs/VALIDATION.md) for current verification limits.
