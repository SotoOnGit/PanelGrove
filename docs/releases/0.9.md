# Panelgrove 0.9

This prerelease brings language editions, page export, custom covers, display adjustments and CB7/7Z support. Local reading statistics remain planned for 1.0.

## New features

- **Language editions:** Versions of the same volume or chapter share one stacked-cover item. The most recently opened edition supplies the cover. Choose a version from a dialog showing its language, cover, reading status and progress. Each edition keeps its own position, bookmarks and history; next-volume suggestions stay in the same language.
- **Page export:** Save or share a selected full page through Android. Archive and folder pages retain their original PNG, JPEG or WebP quality; PDF pages export as PNG. Reader zoom and display adjustments are excluded.
- **Custom covers:** Choose or remove a book's library cover without changing its source document. Covers persist through reopening, rescanning and relinking.
- **Contrast and gamma:** Adjust page appearance with a live preview, using default, series or book settings. Adjustments are included in JSON backups.
- **CB7 / 7Z:** Read solid and non-solid archives using supported LZMA, LZMA2, stored, Deflate and PPMd compression, with the existing metadata, page ordering and reading-data behavior.

## Updating

Export a JSON backup before updating and keep your manga files separately. Install this release's signed APK over public 0.1.6 to retain your library and reading data.

## Known limits

- Local reading statistics are not available yet.
- Custom cover images stay on the current installation and are not included in JSON backups.
- Encrypted and multipart archives, unsupported 7Z compression methods such as BZip2, and EPUB remain unsupported.
- PDF page exports retain the full page and aspect ratio within a 2048 × 3072 pixel limit.
